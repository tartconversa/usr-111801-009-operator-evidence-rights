# 景区资料语义

来源可以是主管部门、景区运营方或合作机构。每份原件有来源、字段说明与摘要，产品修订引用原件，交付时按领取方、用途和来源辖区核对许可。受理人员应能区别来源事实、内部编排和已交付凭据。

当前项目围绕运营方更替时的材料使用权开展资料协作。正式公告、复核观察和运营材料各有发布主体；示例记录不代表真实景区状态。

## 运营关系与材料使用权的关系

- 景区（site）与运营方任期（tenure）描述运营关系沿革：谁在哪个时段在任，可回答“某时点的在任运营方是谁”。
- 经营权接手（handover）只登记交接事实与回执编号，不携带材料授权；材料是否随经营权移交，取决于许可是否覆盖新团队。
- 许可（grant）独立于运营关系存在：来源级许可覆盖来源下全部原件版本；补签许可可限定到具体版本，未在范围内的版本仍不可用；许可可撤销，撤销后所有判断实时失效。
- 可见性清单与复核引用校验只暴露元数据、指纹和实时可用状态，原件正文必须通过统一关口（gate）后才能取得。
- 交付回执快照交付时点的在任运营方、许可编号与策略修订号，作为旧结论的历史依据永久保留；事后撤销或经营权再变更不回溯改写回执，但会阻断新的取件与交付。
